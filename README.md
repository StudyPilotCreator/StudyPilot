# StudyPilot

Your personal planner for school, activities, and everyday life.

## Features
- First-run setup for recurring school days and school hours.
- Add recurring activities such as sports, music lessons, and clubs.
- Add dated events and tasks with duration and priority.
- Calendar with recurring weekly schedule.
- Local browser storage; no account or app server required.
- Export/import a JSON backup.
- Installable web-app structure and offline cache.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site. The expected URL is:
   https://StudyPilotCreator.github.io/StudyPilot/

Then open the HTTPS URL in Safari on your iPhone and use **Share → Add to Home Screen**.

## Data and privacy
The app stores your schedule, routines, tasks, and events in local browser storage on each device. There is no cross-device synchronization and no remote database. Treat the repository as public: do not put personal timetable data here; enter it only inside the app.
